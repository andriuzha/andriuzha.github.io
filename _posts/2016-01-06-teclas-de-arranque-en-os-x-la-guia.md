OS X te permite realizar una combinación de teclas al arrancar tu Mac para realizar ciertas acciones, estas casi siempre son de mantenimiento, pero también puedes acceder a otras opciones.

A continuación daremos la combinación de teclas que se deben de mantener presionadas y una descripción de su funcionamiento.

Cada una de estas combinaciones las debes de pulsar mientras se reproduce el sonido de arranque.

| Teclas | Descripción |
| --- | --- |
| `⇧` | Inicia el sistema en modo seguro. Las extensiones personalizadas no se cargarán. Es muy útil cuando se instalan archivos o daemons que puedan estar generando conflictos con el sistema. |
| `⌥` | Muestra el Gestor de Arranque. Nos da la posibilidad de escoger desde qué unidad queremos arrancar la Mac, ya sea un instalador USB o un DVD del sistema o una partición en la que tengamos instalada otra versión de OS X u otro sistema operativo. |
| `C` | Arranca el sistema desde una unidad óptica o una USB. |
| `D` | Inicia el Apple Hardware Test o Diagnósticos de Apple, dependiendo de qué versión de Mac tengas. No todas las versiones cuentan con esta utilidad. |
| `⌥D` | Inicia el Apple Hardware Test o Diagnósticos de Apple a través de internet. Es necesaria una conexión a internet. |
| `N` | Inicia desde un servidor NetBoot compatible (disponible sólo para OS X Server). |
| `⌥N` | Inicia desde un servidor NetBoot compatible utilizando la imagen de arranque por defecto (disponible sólo para OS X Server). |
| `⌘R` | Iniciará la partición de recuperación si está disponible. |
| `⌘⌥R` | Iniciará la partición de recuperación desde internet. La descarga aproximada es de 500 MB. Requiere conexión a internet. |
| `⌘⌥PR` | Restablece la NVRAM, mantén pulsadas las teclas hasta que escuches el segundo sonido de reinicio. La NVRAM es una porción de memoria que contiene ajustes de arranque y funcionamiento de tu Mac. |
| `⌘S` | Inicia en modo Terminal (usuario único). |
| `T` | Inicia el sistema en modo destino a través de una conexión Thunderbolt o Firewire a otro Mac. Se mostrará como un disco duro externo. |
| `X` | Inicia desde un volumen que no es predeterminado, esto se utiliza por ejemplo cuando tenemos instaladas dos versiones de OS X y queremos que arranque con la versión alternativa. |
| `⌘V` | Inicia el sistema en modo verboso. Se mostrarán todos los pasos de arranque del sistema. De existir algún problema de arranque se detendrá donde este se origine y nos los mostrará. Pudiendo así determinar qué medidas tomar. |
| `⏏` (`F12`) | Expulsará todas las unidades extraíbles. Por ejemplo, un DVD. |

Ahora dispones de todos los modos de arranque, no es mala idea guardar o imprimir esta página para futuras referencias.
